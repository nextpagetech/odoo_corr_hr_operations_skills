Odoo HR and Manufacturing

HR Operations Skills

Connects corrugation operation types with employee Operations skills and uses those skills when selecting employees for work orders.

Overview

HR Operations Skills adds an Operations skill type with levels for employees and syncs operation skills from the corrugation engine. It then uses those skills to filter and rank employees in work order employee selection.

Key Features

Operations skill type

Adds an Operations skill type with Trained, Competent, and Expert levels.

Operation skill sync

Creates HR skills from corrugation operation names using the corrugation operation type source.

Work order employee filtering

Restricts work order employee choices to active employees who match work center categories and operation skills.

Skill-aware employee ranking

Ranks employee search results by matching skill level and recent operation performance when available.

Picker override option

Adds a manager-only option to show all base-allowed employees when no skilled employee should be selected manually.

Employee skill selection cleanup

Filters the employee skill type selector to exclude Soft Skills in the skill selection popup.

How It Works

  1. Install the module with HR Skills, Corrugation MRP Bridge, and Workorder Employee Picker.
  2. The module seeds the Operations skill type and operation skill levels.
  3. The post-install hook syncs corrugation operation names into HR skills.
  4. Assign Operations skills to employees in HR.
  5. When selecting employees on work orders, the addon filters and ranks employees by matching operation skill.

Benefits

  • Helps align work order assignment with employee operation skills.
  • Reduces manual employee filtering during manufacturing work order execution.
  • Supports controlled override for managers when the skilled list is empty or insufficient.
  • Keeps operation skill records synchronized from the corrugation operation source.
